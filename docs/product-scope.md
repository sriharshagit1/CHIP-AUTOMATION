# ChipPilot product scope

## V1
- Regression failure investigation
- RTL/Git context
- Controlled patch proposal
- Isolated verification
- Evidence reports

## V2
- CI-native repository integration
- Historical failure retrieval at team scale
- Human-reviewed pull request workflow
- Broader simulator/tool adapters

## Long-term
- Verification engineering automation
- RTL debugging and review
- Synthesis/STA/DFT workflow assistance
- Post-silicon engineering knowledge

The product should expand only when each workflow has measurable engineering value and safe verification boundaries.
