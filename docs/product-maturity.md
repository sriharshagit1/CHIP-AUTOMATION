# Product maturity gates

## Gate 1 — V1 validated
- reproducible benchmark
- simulator-backed verification
- blind evaluation
- provenance-rich reports
- green CI

## Gate 2 — V2 useful
- PR/CI ingestion
- repository indexing
- automatic regression triage
- test selection
- persistent verified memory
- engineer review workflow

## Gate 3 — V3 platform
- UVM-aware analysis
- assertions and coverage
- formal/debug adapters
- scheduling
- team dashboards
- controlled pilot evidence

## Gate 4 — V4 platform
- synthesis/STA/DFT/post-silicon adapters
- cross-stage knowledge graph
- enterprise permissions/audit
- reproducible execution environments
- multi-project memory

Each gate requires reproducible execution and measurable customer value.
