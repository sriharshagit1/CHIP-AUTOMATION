# ChipPilot — path to the AI Engineering OS for Silicon

V1 is deliberately narrow: regression failure investigation and verified repair.

## V2 — Engineering Repository Agent
- repository-aware context
- CI/PR events
- regression orchestration
- failure clustering and test selection
- organization-specific verified memory
- investigation reports in PRs

## V3 — Verification Engineering Platform
- testbench/UVM context
- assertion generation
- coverage-gap analysis
- failure minimization
- formal-debug assistance
- simulation scheduling
- verification knowledge graph

## V4 — Silicon Engineering OS
- RTL/debug workflows
- synthesis and lint analysis
- STA investigation
- DFT/test debug
- post-silicon log and trace analysis
- cross-stage engineering memory
- unified evidence and provenance

## Product flywheel
Failure → investigation → verified repair → engineering memory → better future investigations.

The moat is the execution layer, verified engineering data, tool integrations, evaluation system, and customer-specific context.
